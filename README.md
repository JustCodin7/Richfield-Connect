# Richfield Connect

## Description
Richfield Connect is a secure academic social platform built exclusively for Richfield students. It allows students to register, create a personal profile, share posts on a community feed, and connect with peers across all Richfield campuses.

---

## Pages
- `index.html` - Home page with welcome banner and feature cards
- `about.html` - About page showing the mission, what is offered, how it works, and campus stats
- `signup.html` - Registration form where students enter their name, student number, campus, email, password, interests, and bio
- `profile.html` - Profile page that displays the students saved information
- `feed.html` - Community feed where students can create posts, like posts, and delete their own posts

---

## Features
- Live profile preview on the signup page that updates as you type
- Form validation on all signup fields with error messages
- Posts saved and loaded using localStorage
- Like and delete buttons on each post
- Sidebar on the feed showing your name, campus, post count, and like count
- Back to top button on every page
- Sticky navigation bar with active page highlighting
- Fully responsive design for tablet and mobile screens

---

## How To Open
Download all files, keep them in the same folder, and open index.html in any browser. No installation needed.
